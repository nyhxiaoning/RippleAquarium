# 自然鱼类几何细化设计

## 目标

在现有七种纯程序化鱼类模型基础上，改善鱼身比例、尾柄、尾鳍和各类鱼鳍的自然度，减少厚重三角块感，同时保留实例化渲染、成长缩放、鱼群运动和稳定 fishId。

## 范围

- 修改 `src/fish/procedural-species.ts` 的七种模型几何和顶点颜色生成。
- 不引入外部 `.glb`、纹理或网络资源。
- 不修改天气、海洋生物、鱼群行为和成长存档接口。
- 每种鱼仍返回一个合并后的 `BufferGeometry` 和一个可释放材质。

## 共享几何策略

- 鱼身使用 28–36 径向分段的椭圆体，并通过纵向缩放/顶点位置让头部更饱满、尾部更窄。
- 追加短尾柄几何，使身体到尾鳍的连接连续，不再直接用大圆锥连接。
- 尾鳍使用带缺口的参数化轮廓，挤出厚度控制在 `0.04–0.12`，并在边缘加入轻微 bevel。
- 背鳍、腹鳍和胸鳍使用薄膜状双面几何，保留少量厚度避免完全消失。
- 合并前统一索引/UV 属性，合并后重新计算平滑法线和包围体。
- 使用顶点颜色表达背腹渐变、侧线、条纹、斑块和鳍部颜色过渡。

## 物种细化

- **沙丁鱼**：缩窄身体和尾柄，银色腹部到蓝灰背部渐变，增加细窄侧线和小型分叉尾鳍。
- **锦鲤**：保留较厚椭圆体，头部更圆，红橙斑块边界柔和，尾鳍宽而薄。
- **小丑鱼**：缩短身体，三条白色环带沿曲面分布，黑色边缘变窄，鳍部改为暖色薄膜。
- **神仙鱼**：保持高体型，背鳍和腹鳍更长更薄，尾柄变窄，竖向条纹随体表渐变。
- **蓝吊**：保持侧扁体型，背腹弧度更自然，黄色尾柄与深蓝主体过渡更清晰。
- **河豚**：圆体更平滑，刺点缩小并减少视觉突兀，胸鳍和尾鳍改为圆润短鳍。
- **海星**：五臂轮廓加入臂根弧度和中心隆起，橙红颜色从中心向臂端平滑过渡。

## 性能与生命周期

- 每个物种保持一套共享几何和材质，实例数量继续由 `InstancedMesh.count` 控制。
- 不在每帧创建几何、材质、数组或 Three.js 对象。
- 现有 `disposeFishMesh`、海星学校 `dispose` 和成长 `setGrowthSizes` 生命周期保持不变。

## 验证标准

- 七种模型均具有平滑法线、顶点颜色和有效包围体。
- 浏览器中鱼身、尾柄和鱼鳍不再呈明显厚重块状。
- 所有鱼类仍能正常运动、成长缩放、切换预设和保存成长记录。
- `npm test`、`npm run typecheck`、`npm run build` 全部通过。
