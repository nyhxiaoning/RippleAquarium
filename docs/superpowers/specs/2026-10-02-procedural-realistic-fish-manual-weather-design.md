# 程序化真实鱼类与手动天气控制设计

## 目标

将新增的神仙鱼、蓝吊和河豚从当前低多边形外观升级为更接近真实鱼类比例与配色的纯程序化 Three.js 模型，同时把天气改为晴天、雨天、雪天、阴天四种可由按钮手动选择的模式，禁止自动循环和随机切换。

## 范围

- 仅修改现有新增鱼种的程序化模型，不引入外部 `.glb` 资源。
- 保留现有 InstancedMesh、鱼群运动、成长缩放和模型加载接口。
- 天气状态只包含 `clear`、`rain`、`snow`、`cloudy` 四种模式。
- 控制面板使用四个互斥按钮，显示当前选中状态。
- 删除自动循环开关与自动切换逻辑。
- 雨天保留降雨视觉效果，雪天新增雪粒子/飘落视觉效果；天气仍通过现有平滑过渡影响光照、鱼速、成长和水面波纹。

## 鱼类模型设计

### 共享建模约束

- 使用高分段 `SphereGeometry` 或 `LatheGeometry` 构造平滑鱼身。
- 通过合并几何体保持每个鱼种一个可实例化模型资源。
- 使用多材质分区或顶点颜色表达真实配色；眼睛、尾柄、鳍和腹部作为独立几何部件。
- 背鳍、腹鳍、胸鳍使用薄片/低厚度几何，并设置适度透明度与双面渲染。
- 模型原点保持在鱼体中心，朝向与现有 `writeFishOrientationQuaternion` 兼容。
- 由现有 `renderScale` 与成长倍率统一控制大小，不引入鱼种独立动画状态。

### 神仙鱼

- 侧扁椭圆体型，身体高度大于厚度。
- 长背鳍、腹鳍与扁平尾鳍，金色/银色身体与深色竖向条纹。
- 眼睛与小型嘴部使用独立深色几何。

### 蓝吊

- 侧扁椭圆体型，背部与腹部圆润过渡。
- 深蓝主体、黑色轮廓分区、黄色尾鳍和尾柄。
- 胸鳍、背鳍、腹鳍使用半透明深蓝薄片。

### 河豚

- 近球形体型，腹部略宽，使用浅色腹部与金棕色背部。
- 添加短胸鳍、背鳍、尾鳍、眼睛和少量圆锥刺点。
- 刺点保持低数量，避免实例化几何过重。

## 天气设计

### 状态与控制

- `WeatherKind` 改为 `"clear" | "rain" | "snow" | "cloudy"`。
- `WeatherState` 不再暴露自动循环行为；控制器 `update(dt)` 只推进当前模式的视觉过渡，不触发模式切换。
- `setWeather(kind)` 是唯一的天气模式变更入口。
- UI 为四个按钮，按钮点击立即调用 `manager.setWeather(kind)` 并刷新当前高亮状态。
- 不保留自动循环复选框、计时器切换或随机切换。

### 效果

- 晴天：高亮度、无降水、低波纹扰动。
- 阴天：中低亮度、无降水、轻微波纹变化。
- 雨天：低亮度、雨滴粒子/波纹增强，鱼速和成长略降。
- 雪天：低亮度、雪花粒子缓慢下落，鱼速和成长适度降低，背景偏冷色。

## 数据流

1. 控制面板按钮调用 `AquariumManager.setWeather`。
2. `WeatherController` 保存当前模式并生成平滑过渡效果。
3. 场景更新循环读取 `WeatherState`/`WeatherEffects`，更新灯光、水面、鱼群速度和成长倍率。
4. 雨雪粒子系统根据 `WeatherEffects.rainIntensity` 与新增的 `snowIntensity` 更新可见性和粒子位置。

## 兼容性与错误处理

- 未知鱼种 key 继续抛出明确错误。
- 未知天气值在 TypeScript 编译期阻止；运行时按钮只产生受支持的四种值。
- 天气切换传入非正数 `dt` 时不推进状态，保持现有暂停语义。
- 鱼类几何体和材质由现有 `disposeFishMesh` 生命周期释放。

## 验证标准

- 三种新增鱼类仍能被鱼群渲染器创建，成长缩放和运动测试不回归。
- 天气测试覆盖四种模式、手动切换、无自动循环和雪天效果。
- `npm test`、`npm run typecheck`、`npm run build` 全部通过。
- 浏览器手动检查四个天气按钮和三种新增鱼类的视觉效果。
