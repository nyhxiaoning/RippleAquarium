# 全鱼类程序化真实外观设计

## 目标

将鱼类目录中的沙丁鱼、锦鲤、小丑鱼、神仙鱼、蓝吊、河豚以及海星统一升级为纯程序化 Three.js 模型，保持现有鱼群运动、实例化渲染、成长缩放和天气系统不变。

## 范围

- 不引入新的 `.glb`、纹理或网络资源。
- 继续使用现有 `createFishMeshByKey`、`FishModelInstance` 和 `InstancedMesh` 管线。
- 现有三个程序鱼（神仙鱼、蓝吊、河豚）继续保留并进一步统一材质参数。
- 将沙丁鱼、锦鲤、小丑鱼和海星从 GLB/临时模型切换为程序化模型。
- 海星属于海洋生物目录，但本次按用户要求纳入真实程序化外观升级。

## 模型设计

### 共享约束

- 每个物种返回一个合并后的 `BufferGeometry` 和一个可释放的 `MeshStandardMaterial`。
- 使用 24–32 个径向分段的平滑身体几何，合并前统一索引/UV 属性，合并后重新计算平滑法线。
- 使用顶点颜色表达身体、腹部、斑块、条纹和鳍的分区，避免每条鱼创建独立材质。
- 所有模型本地前方沿 +Y，兼容现有鱼群姿态四元数。
- 由现有 `renderScale` 与成长倍率控制大小，不添加物种专用动画状态。

### 沙丁鱼

- 细长梭形椭圆体，银色腹部、蓝灰背部和深色背线。
- 窄尾柄、分叉尾鳍、背鳍、腹鳍和两枚侧眼。
- 保持轻量，以鱼群数量较高时的实例化性能为优先。

### 锦鲤

- 粗壮椭圆体，白色基础色，红橙色不规则斑块和浅金色腹部。
- 宽尾鳍、背鳍和胸鳍，鳍部使用较浅的暖色顶点区域。
- 模型保持较高体积但不添加逐鳞片几何。

### 小丑鱼

- 橙色椭圆体，三条白色环带并带窄黑边。
- 圆形尾鳍、背鳍和胸鳍，配色通过顶点位置分区生成。
- 继续使用珊瑚礁栖息层和现有小丑鱼行为，不更改运动逻辑。

### 神仙鱼、蓝吊、河豚

- 复用当前程序化模型接口和实例化生命周期。
- 统一使用平滑法线、顶点颜色与材质粗糙度，保持与新增物种一致的视觉质量。

### 海星

- 使用五臂径向对称的低厚度挤出几何。
- 橙红色渐变顶点颜色，中心略厚、臂端略窄。
- 颗粒感通过少量凸点几何或顶点颜色模拟，不生成高密度鳞片。
- 保留海星现有底栖行为和成长记录接口。

## 数据与渲染接入

1. 扩展 `ProceduralFishKey` 与 `isProceduralFishKey`，加入 `sardine`、`koi`、`clownfish`、`starfish`。
2. `createFishModelInstanceByKey` 对这些 key 直接调用程序化模型工厂。
3. `species-catalog.ts` 的模型 key 保持不变，避免改变预设和存档中的物种 ID。
4. 保留旧 GLB 加载作为无关资源的兼容代码，但默认鱼群不再依赖 GLB 模型。

## 错误处理与性能

- 未知程序模型 key 抛出带 key 的明确错误。
- 合并几何失败时立即抛出错误，避免创建不可渲染的实例网格。
- 沙丁鱼 260 条容量、锦鲤 120 条容量和小丑鱼 40 条容量下仍使用单个实例网格。
- 海星数量较少，使用固定少量凸点，避免创建大量独立对象。

## 验证标准

- 七个物种都能通过 `createFishModelInstanceByKey` 创建有效几何、法线和顶点颜色。
- 现有鱼群行为、成长缩放、物种目录和天气测试全部通过。
- `npm test`、`npm run typecheck`、`npm run build` 全部通过。
- 浏览器中默认鱼缸可同时看到七种真实比例/配色的程序化模型，且切换样式、调整数量和成长记录不回归。
