# 纯程序化海绵宝宝主题景观设计

## 目标

将鱼缸中鱼类之外的海绵宝宝主题景观改为纯程序化 Three.js 内容，并按照用户提供的参考图重新组织构图：左侧菠萝屋与派大星，中间海绵宝宝，中右章鱼哥，右侧蟹老板。保留现有主题开关、缩放、待机动画、碰撞避让和资源释放接口，不影响鱼群、天气和成长系统。

## 范围

- 新增独立程序化角色：海绵宝宝、派大星、章鱼哥、蟹老板。
- 将菠萝屋改为程序化住宅；现有章鱼哥房屋和蟹堡王程序化道具继续纳入同一套主题对象生命周期。
- 新增共享的程序化卡通几何、材质和面部部件构建器。
- 更新主题目录、类型、预设布局、碰撞/避让区域和测试。
- 旧的 `spongebob-patrick` 配置保留兼容读取，但运行时由两个独立程序化对象替代，不加载旧 GLB。

## 非目标

- 不修改鱼类模型、鱼群行为、天气切换、成长存档或海洋生物系统。
- 不引入外部 GLB、纹理、音频、网络资源或新的运行时依赖。
- 不实现点击对话、任务、收集品或小游戏。

## 程序化对象与模块边界

### 共享部件层

新增 `src/theme/procedural-parts.ts`，只负责可复用的纯几何构建：

- 圆角盒体、椭圆体、胶囊体、圆柱、低多边形球体和曲线轮廓。
- 眼睛、眼柄、嘴、手臂、腿、鞋、钳子和叶冠等卡通部件。
- 顶点颜色、轮廓色、服装分区和共享 `MeshStandardMaterial` 创建。
- 几何合并、包围盒计算和可释放资源登记。

部件构建只在主题对象创建或重建时运行，不在每帧创建 Three.js 对象、数组、材质或几何。

### 角色组合层

在 `src/theme/characters.ts` 中保留 `createThemeCharacter` 入口，并新增四个独立分支：

- `spongebob`：黄色圆角盒体、浅色孔洞、白色大眼睛、棕色裤子、红色领带、白衬衫、细腿和黑鞋。
- `patrick`：粉色锥形/胶囊身体、绿色短裤、紫色花纹、粗手臂和短腿。
- `squidward`：青绿色椭圆头、下垂眼睑、长鼻子、四条可见触手和棕色上衣。
- `mr-krabs`：红色椭圆身体、双眼柄、左右蟹钳、蓝色衬衫和紫色裤子。

每个角色返回现有主题生命周期所需的 group、update、resize、setAnimationEnabled、interactionAnchor 和 dispose 能力。待机动作保持低幅度：眼柄、触手或手臂缓慢摆动，主体位置保持稳定。

### 住宅与道具层

在 `src/theme/props.ts` 中新增程序化 `pineapple-house`：橙黄色菠萝主体、交叉表皮纹理、绿色叶冠、蓝色圆窗、木色拱门和底座。现有 `squidward-house`、`krusty-krab` 继续使用共享部件与同一 dispose/碰撞接口。

## 目录与兼容性

扩展主题类型：

- `ThemeCharacterId = "spongebob" | "patrick" | "squidward" | "mr-krabs"`
- `ThemePropId = "pineapple-house" | "squidward-house" | "krusty-krab"`

目录为每个对象提供中英文标签、默认缩放和对象类型。历史配置中的 `spongebob-patrick` 资产标识不删除；归一化阶段将它映射为 `spongebob` 与 `patrick` 两个主题对象，且不再调用 `src/decor/spongebob-patrick.ts` 的 GLB 加载器。历史 `pineapple-house` 配置继续保留 ID，但运行时解析到新的程序化 prop。

## 参考图布局

默认大缸使用参考图的左到右构图：

1. 后左：菠萝屋，作为背景锚点。
2. 左前：派大星，缩放略大于海绵宝宝。
3. 中央：海绵宝宝，作为视觉焦点。
4. 中右：章鱼哥，位置略后并保持较高的触手轮廓。
5. 右前：蟹老板，横向占位较宽但不遮挡海绵宝宝。

珊瑚礁、深海预设按缸体尺寸缩小并重新计算横向锚点；小缸将角色缩放到约 65%–75%，默认隐藏菠萝屋、章鱼哥房屋和蟹堡王等大体积道具。所有对象位置必须在当前预设的缸体 footprint 内。

## 材质与视觉规则

- 使用 `MeshStandardMaterial` 和顶点颜色，不使用纹理贴图。
- 角色采用鲜艳卡通颜色，并用稍深的轮廓色差分隔部件。
- 海绵宝宝使用黄色主体与棕/红/白服装分区；派大星使用粉、绿、紫；章鱼哥使用青绿、棕；蟹老板使用红、蓝、紫；菠萝屋使用橙黄、绿、蓝、木色。
- 所有合并几何计算平滑法线、包围盒和包围球；材质和几何均可安全释放。

## 数据流与生命周期

主题目录和预设生成 `ThemeEntry`，主题管理器根据 entry 创建角色或道具。角色/道具把包围盒和避让区域交给场景管理器，鱼群只读取碰撞结果，不持有主题对象引用。主题对象的缩放通过现有 `resize` 接口更新，待机动画通过现有 `update` 接口更新，切换预设或卸载时调用 `dispose`。

主题对象不进入鱼类成长存档；主题设置仍属于运行时场景配置。旧配置归一化后必须得到独立的海绵宝宝和派大星 entry，重复归一化不能产生重复对象。

## 验证标准

- 四个程序化角色和菠萝屋都能创建有效的非空几何、顶点颜色、法线和包围盒。
- 默认预设的布局顺序符合“菠萝屋 → 派大星 → 海绵宝宝 → 章鱼哥 → 蟹老板”，且对象不越界。
- 旧 `spongebob-patrick` 配置能正常归一化，运行时不发起旧 GLB 请求。
- 显示/隐藏、缩放、待机动画、碰撞避让和 dispose 不回归。
- 鱼类成长、天气按钮、鱼群数量与现有海洋生物不受影响。
- `npm test`、`npm run typecheck`、`npm run build` 全部通过，并完成浏览器预览检查。
